# # Blog con Autenticación

## Descripción
Aplicación web tipo blog con autenticación básica y CRUD de publicaciones.

## Tecnologías
- HTML
- CSS
- JavaScript
- LocalStorage

## Funcionalidades
- Registro
- Login
- Logout
- Crear publicaciones
- Editar publicaciones
- Eliminar publicaciones

## GitHub
Proyecto desarrollado usando ramas, commits y pull requests.
